# konusgruppsoft.ru

Сайт АО «КонусГрупп Софт» (АО «КГ Софт»): статические страницы без сборки на хостинге.

Исходник и сборка — в репозитории `kgsoft`: тексты разделов в `tools/site/build.py`,
стили и скрипт в `site/assets/`. Сюда копируется готовая папка `site/`; править страницы здесь руками не нужно.

## Разделы

`/` главная · `/vnedrenie/` · `/proekt/` · `/ispytaniya/` · `/razrabotka/` · `/oborudovanie/` · `/oez/` · `/o-kompanii/`

Сведения под приказ Минцифры № 511 (реквизиты, ИТ-коды, продукты, стоимость, языки) — на `/o-kompanii/`.

## Оформление

В системе larpit.tech: янтарный акцент `#e8a33d`, шрифты Oswald / PT Sans / JetBrains Mono, сигнальная полоса сверху.
Тёмная и светлая темы: по настройке системы посетителя, переключатель в шапке. Цвета — переменные `:root` в `assets/site.css`.

## Деплой в Timeweb Cloud (App Platform)

- Тип приложения: **Статический сайт (HTML/CSS/JS)**.
- Репозиторий: `semedal/konusgruppsoft-site`, ветка `main`, корень — директория сборки.
- Деплой автоматический по пушу в `main`; домен `konusgruppsoft.ru` привязан в настройках приложения.
