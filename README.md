# konusgruppsoft.ru

Одностраничный сайт АО «КонусГрупп Софт» (АО «КГ Софт»).
Один самодостаточный файл `index.html` — без сборки, стили и SVG-логотип инлайном.

Дизайн — в системе larpit.tech: фон `#0e1013` с сеткой, янтарный акцент `#e8a33d`,
шрифты Oswald / PT Sans / JetBrains Mono (Google Fonts), сигнальная полоса сверху.
Токены — в `:root` в начале `<style>`.

## Локально

Открыть `index.html` в браузере — ничего поднимать не нужно.

## Деплой в Timeweb Cloud (App Platform)

- Тип приложения: **Статический сайт (HTML/CSS/JS)**.
- Репозиторий: `semedal/konusgruppsoft-site`, ветка `main`, корень — директория сборки.
- Деплой автоматический по пушу в `main`; домен `konusgruppsoft.ru` привязан в настройках приложения.

## Что править

- Тексты, почта, реквизиты — прямо в `index.html`.
- Цвета и шрифты — переменные `:root`; менять синхронно с larpit.tech.
